# Development Workflow

The project uses Git for version control.

## Main Branch

The `main` branch contains stable project versions.

## Feature Branches

New functionality is developed in separate feature branches.

Example:

    git checkout -b feature/new-feature

## Commits

Commits should describe the implemented change.

## Pull Requests

Completed features are pushed to GitHub and submitted as Pull Requests.

Pull Requests are reviewed before merging.

## Testing

Changes must be tested before merging.

## Merge Conflicts

If a conflict occurs, the conflicting files are inspected and manually corrected before the merge is completed.
